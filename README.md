# Sistema Média

O **Sistema Média** é uma aplicação simples desenvolvida em **Python**, cujo objetivo principal é calcular a média final de um aluno e determinar se ele foi **aprovado ou reprovado**.

O sistema utiliza três avaliações:

* **NP1:** peso 10
* **NP2:** peso 10
* **PIM (Projeto Integrado Multidisciplinar):** peso 10

A média mínima para aprovação é **7,0**.

### Cálculo da média

A média final é calculada utilizando a seguinte fórmula:

**Média = (NP1 × 4 + NP2 × 4 + PIM × 2) / 10**

Após o cálculo, o sistema compara a média obtida com a média mínima necessária para aprovação e informa o resultado ao aluno.
